SECURITY.md & Vulnerability Disclosure

Security Policy

CyberTwin Max is built with a Zero-PII Storage Guarantee. Entered email addresses are queried against public breach datasets (XposedOrNot) and discarded from memory upon browser refresh. Passwords are never sent over the network—only the first 5 characters of SHA-1 hashes are queried using k-anonymity.
